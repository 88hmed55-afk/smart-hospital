# تقييم المخاطر الأمنية (Risk Assessment) — Smart Hospital

> قالب تنفيذي وفق HIPAA §164.308(a)(1)(ii)(A). يجب تحديثه سنوياً أو عند تغيير جوهري. مقياس الاحتمال والأثر: 1 (منخفض) إلى 5 (مرتفع). درجة الخطر = الاحتمال × الأثر.

## 1. منهجية
1. حصر الأصول والبيانات (PHI، مالية، تشغيلية، أسرار).
2. تحديد التهديدات ونقاط الضعف القابلة للاستغلال.
3. تقدير الاحتمال والأثر وتصنيف الخطر: منخفض (1–6)، متوسط (7–12)، مرتفع (13–19)، حرج (20–25).
4. اختيار معالجة: تخفيف، نقل، تجنب، قبول موثق.
5. تعيين مالك وتاريخ استحقاق.

## 4. خطة المعالجة ذات الأولوية
1. **تفعيل إلزام MFA** للمسؤولين والأطباء عبر `smarthospital.mfa.requiredRoles` (R-01, R-12) — البنية جاهزة، يلزم قرار وسياسة وتسجيل الحسابات.
2. **إلزام HTTPS بشهادة موثوقة** (R-06).
3. **تشفير النسخ الاحتياطية At Rest** (R-02).
4. **خزنة أسرار لمفتاح MFA وكلمة مرور DB** ونسخ احتياطي منفصل للمفتاح (R-13).
5. **أرشفة تدقيق WORM لمدة 6 سنوات** (R-03).
6. **اختبار اختراق مستقل** قبل الإطلاق التجاري (R-04, R-09).
7. **إزالة بيانات العرض قبل الإنتاج** (R-10).
