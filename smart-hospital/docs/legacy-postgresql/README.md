# PostgreSQL / earlier Smart Hospital design archive

All files in this folder preserve the earlier PostgreSQL / Jakarta EE 11 design history and the v0.x implementation notes. They are not part of the current Jakarta EE 10 / MySQL installation path. Do not execute the historic PowerShell scripts or SQL instructions from these notes for the current package.

For the active edition, use the root `README.md`, `docs/NETBEANS_WINDOWS_SETUP_AR.md`, `docs/EE10_MYSQL_PORTING.md`, and the current API contract at `docs/api/openapi-v1.yaml`.
